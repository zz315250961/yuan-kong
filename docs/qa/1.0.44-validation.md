# LinkRemote 1.0.44 候选验收

## 发布闸门

用户要求先完成 iOS 剩余问题（包括双向语音）和自动测试，再更新服务器及域名下载链接。当前文档是进行中的验收记录，**不是发布批准或所有功能通过声明**。线上保持 1.0.42，旧 `v1.0.43` 标签、已有草稿及候选原始证据不覆盖。

候选源版本为 Cargo 1.0.44 / Flutter 1.0.44+76。Windows x64、Android arm64 和管理网页通过源码 SHA 固定的 candidate-only 工作流重新打包；该模式只上传 run artifacts，不创建标签、不改发布草稿、不部署。iOS 单独构建 arm64 无签名设备 App 与 Intel Simulator App；两者均不是签名 IPA。

## 本轮修复范围

- 扫码入口接入首页，实际相册文件经独立 isolate 解码；对相机、相册和深链统一校验。区分设备连接与服务器配置确认，防超长/非法码、自连、重复导航以及离页后迟到回调；取消扫码不关闭现有连接。停止把链接和密码写入调试日志。
- iOS 控制端新增双向通话接线：工具栏、麦克风授权、AVAudioSession 前台策略、远端接受协议、独立 CPAL 录音及 Opus 上行。48 kHz mono / 32 kbps / 20 ms；PCM、待发送语音队列均有界，音频回调不编码、不联网。
- 通话启动在独立可取消异步任务，真实 PCM 编码成功前不显示已连接。每个通话带标识，取消后的旧启动结果、错误及音频不能影响重拨。45 秒未响应、手动结束、断线、离页、后台、音频中断均清理；权限弹窗 inactive 不误停，回前台不自动开麦。
- iOS 下行输出回调使用固定栈缓冲和非等待锁；缺数据填静音，不在 CoreAudio 回调休眠或分配 Vec。其他平台路径保持不变。
- MSI/Web 包保留 AGPL、NOTICE 和上游归属；候选产物记录源码、版本、文件大小和 SHA-256；Android 必须通过既有签名证书及 16 KiB 对齐检查，不把 debug 包当可升级正式包。

### 同账号设备不显示修复（2026-10-20）

用户确认电脑、手机、网页都看不到同账号已登录设备。实际 HTTP 红测复现：两个客户端登录均成功，但远控 ID 未就绪时设备被静默丢弃；随后认证心跳路由返回 404，无法补登记。旧网页测试手工 upsert 设备，绕过了这一缺口。

现按已认证账号和稳定安装 UUID 登记，ID 稍后就绪时更新同一行；缺少原生 UUID 时持久化独立 UUID，不用 `0` 充当身份。客户端登录/恢复、列表前及 60 秒周期补登记；本机登记慢时列表最多单独等 4 秒，仍读取其他设备，并提示同步问题。旧服务可回退到认证 currentUser。认证补登记不接受 body 中伪造的账号归属。

Flutter 和网页均保护账号/API 切换后的迟到回包与旧删除确认；请求使用每个 Dart isolate 随机 UUID scope 加序号、不含账号或 token 的 nonce，隔离原生按 URL 缓存异步结果的状态。新增实际 spawn 两个 isolate 的红绿回归，避免两个引擎首个序号相同。网页 E2E 已替换手工设备 upsert，真实执行多个原生登录、心跳补 ID、网页读取，并验证跨账号迟到 200/401 不覆盖新账号。仅控制端 iOS 与 ID 未就绪设备正常显示、禁用无效连接/复制；登记记录不冒充实时在线探测。

语音另补 UI 同步取消登记和代次墓碑：取消早于远端接受、任务首次 poll 或网络 Close 处理时也能停止所属录音；旧线程退出不能清掉新代次，旧 Ready / 语音消息另校验当前 owner epoch。跨页面重建原生 owner 唯一，权限迟到结果不会结束新页面通话。原生音频策略在 CPAL 收尾期间作有限清理重试，不重新开麦。

另以两项红绿回归复现关闭/重拨问题并修复：Dart 将请求入队和关闭入队串行，立即清理原生音频，不等待网络；Rust 清本地状态、发一次必要 closed，再通过同一 session stream 发独立 close ack，均在网络写 await 前完成。协调器在 ack 到达前保持关闭中，防止旧唯一 closed 误停新麦；空闲重复 close 不再发重复 closed，但仍 ack。dispose 先禁止重拨再释放屏障。协议层远端 close 本身不含通话代次，不能宣称任意迟到远端关闭包可被区分。

## 尚需完成的发布条件

- 当前候选源码的真实 Rust 测试、iPhoneOS / Simulator 全量编译及产物核验，以及新 Windows / Android / Web 包核验，均以对应 run 的最终证据回填。
- 签名 iPhone/iPad：双向可听、拒绝授权后恢复、远端拒绝/超时、来电与蓝牙拔出、背景/离页关闭和停止后麦克风指示。用户目前没有可用 Mac 或开发者签名环境，unsigned App 不可直接安装，不能以云构建替代。
- 音质：锁定 CPAL 使用 RemoteIO，`.voiceChat` 本身不启用 VoiceProcessingIO 回声消除。界面已提示建议耳机；免提 AEC/AGC 未实现，不宣称扬声器回声与音质已验收。
- 原生相机/照片权限、冷/暖深链实际交付与横屏恢复；Android 真机触控右键到远端 OS 的验证；Windows 安装/升级/卸载与设置保留；真实 SMTP 投递；网络切换重连、剪贴板/文件传输和持续画质/帧率实测。
- 120 FPS 是 Windows 被控端能力目标，不是自动测试测出的稳定值；Android 被控端当前上限 60 FPS。设备/显示器、编码器、解码、网络与温控需实际测量。
